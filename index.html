Admin gera todas as senhas e distribui o sistema (este arquivo HTML) para cada operador.

Cada operador valida entradas normalmente. O sistema salva tudo localmente.

Cada operador clica em Exportar Sessão e envia o arquivo para o admin.
4️⃣
Pós-evento
Admin importa todos os arquivos e clica em Merge. Resultado consolidado enviado ao Sheets.
